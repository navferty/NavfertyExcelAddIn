Лучшие бесплатные надстройки для Excel

Короткий список бесплатных надстроек, которые стоит установить, и для чего каждая хороша.

На ленте Excel много возможностей, но для многих повседневных задач всё ещё требуется слишком много шагов. Эти бесплатные надстройки и встроенные дополнения закрывают часть пробелов. Перед использованием с корпоративными данными проверьте лицензию и политику конфиденциальности каждой.

Встроено в Excel (но выключено)

  • Пакет анализа – регрессия, гистограммы, t-тесты и другая статистика. Включается в Файл → Параметры → Надстройки → Управление: Надстройки Excel → Перейти.
  • Поиск решения – оптимизация с ограничениями, в том же диалоге.
  • Power Query и Power Pivot – импорт, преобразование и моделирование данных. В современных версиях Power Query находится на вкладке Данные.

От Microsoft

  • Магазин надстроек Office (Вставка → Получить надстройки) содержит и бесплатные, и платные продукты. Примеры: Microsoft Visio Data Visualizer, Power BI и несколько инструментов для диаграмм.
  • Power Query для старых версий (2010/2013) – бесплатная отдельная загрузка.

Открытые и сообщественные

  • Navferty's Excel Add-In – бесплатный набор инструментов с открытым исходным кодом для работы с содержимым ячеек: преобразование текста в числа, удаление пробелов, замена похожих кириллических букв, транслитерация, сумма прописью (русский, английский, французский), смена регистра, разъединение ячеек с заполнением, подсветка дубликатов, поиск всех ячеек с ошибками, проверка значений (включая российские ИНН), экспорт в SQLite и Markdown, создание примера XML по XSD и проверка XML. Это классическая VSTO-надстройка для настольного Excel под Windows. Исходный код и установщик – на GitHub.
  • Kutools, ASAP Utilities и набор Ablebits предлагают гораздо больше команд. Они бесплатны с ограничениями или в пробный период, а затем платные, поэтому прочтите условия.
  • Excel-DNA и xlwings – не надстройки для установки, а фреймворки для разработчиков: функции .NET на листе и Python с Excel.

Как выбирать

  • Делает ли она то, что нужно вам хотя бы раз в неделю? Большой набор инструментов, из которого вы используете две кнопки, – не выигрыш.
  • Работает ли она офлайн и хранит ли данные на вашей машине? Проверьте политику конфиденциальности на предмет отправки ячеек на сервер.
  • Можно ли посмотреть исходный код или хотя бы доверять издателю?
  • Подходит ли она вашему Excel (32 или 64 бита, версия, Windows или Mac, настольный или веб)? Многие надстройки работают только в настольном Excel под Windows.
  • Можно ли её чисто удалить?

Установка сторонней надстройки

Для надстроек с установщиком запустите установщик и перезапустите Excel. Другие поставляются как файлы .xlam или .xll: положите файл в доверенную папку и добавьте его через Файл → Параметры → Надстройки → Перейти → Обзор. Если Excel блокирует файл, щёлкните по нему в проводнике правой кнопкой → Свойства и поставьте галочку Разблокировать. Шаги установки надстройки Navferty есть на главной странице.
