Подсветка дубликатов в Excel без формул

Условное форматирование, удаление дубликатов и что делать, если нужно видеть, какие строки совпадают.

Дубликаты в списке клиентов, реестре счетов или перечне идентификаторов могут привести к двойным платежам и неверным итогам. Прежде чем что-то удалять, полезно их увидеть.

Условное форматирование

Выделите столбец, затем Главная → Условное форматирование → Правила выделения ячеек → Повторяющиеся значения. Каждое значение, встречающееся более одного раза, получит цвет. При редактировании данных подсветка обновляется автоматически.

Что учесть:

  • Сравнение не учитывает регистр: abc и ABC считаются одним значением.
  • Пробелы на конце делают значения разными. Сначала очистите текст (см. удаление лишних пробелов).
  • Числа длиннее 15 цифр (номера карт, длинные идентификаторы) сравниваются только по первым 15 цифрам, поэтому Excel может отметить значения, различающиеся последними цифрами. Для таких столбцов используйте правило с формулой и точным сравнением, например =СУММПРОИЗВ(--($A$2:$A$1000=$A2))>1.

Дубликаты по нескольким столбцам

Если дубликатом считается одинаковое сочетание, скажем, имени и даты, встроенного правила недостаточно. Используйте правило с формулой:

=СЧЁТЕСЛИМН($A$2:$A$1000;$A2;$B$2:$B$1000;$B2)>1

и примените его ко всей таблице.

Удалить дубликаты

Данные → Удалить дубликаты удаляет повторяющиеся строки, оставляя первую. Можно сравнивать только выбранные столбцы. Отменить действие можно только сразу по Ctrl+Z, поэтому работайте с копией данных.

Пометить, а не удалять

Вспомогательный столбец с =СЧЁТЕСЛИ($A$2:$A2;A2) даёт 1 для первого вхождения, 2 для второго и так далее. Отфильтруйте значения больше 1, чтобы увидеть только повторы, или оставьте первые вхождения и разберите остальные.

С надстройкой

Команда Подсветить дубликаты (Highlight Duplications) окрашивает повторяющиеся значения в выделенном диапазоне, причём каждая группа одинаковых значений получает свой цвет. Так видно, какие строки связаны между собой, чего не показывает один цвет в условном форматировании. Подсветка – это обычная заливка ячеек, поэтому книгу она не замедляет.

Команда надстройки для этой задачи: Подсветить дубликаты.
