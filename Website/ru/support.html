Поддержка и обратная связь

Нашли проблему или не хватает функции? Создайте обращение на GitHub. Кнопка Информация в конце вкладки Navferty's Tools открывает диалог с теми же ссылками.

Сообщить об ошибке

Сообщить об ошибке на GitHub

Пожалуйста, укажите:

  • версию надстройки (скопируйте её значком рядом с версией в диалоге Информация) и версию Excel;
  • шаги для воспроизведения и ожидаемый результат;
  • по возможности небольшой пример книги без конфиденциальных данных;
  • файл журнала, лучше записанный с подробным журналированием.

Предложить функцию

Предложить функцию на GitHub

Сначала просмотрите существующие обращения: если идея уже есть, поддержите её или оставьте комментарий. Опишите задачу, которую нужно решить, и пример данных, а не только желаемое решение.

Журналы

Надстройка пишет отдельный файл журнала на каждый день. Чтобы открыть папку, нажмите Информация → Открыть папку с журналами или перейдите по пути:

%LOCALAPPDATA%\Navferty\ExcelAddIn\logs

Приложите последний файл .log к обращению. Файлы больше 5 МБ делятся на части, а файлы старше 14 дней удаляются автоматически.

Подробное журналирование

По умолчанию записываются только важные события и ошибки. Чтобы записать подробности:

  1. Нажмите Информация и включите Подробный журнал.
  2. Воспроизведите проблему.
  3. Приложите файл журнала к обращению.

Подробный журнал отключается при перезапуске Excel.

Конфиденциальность

Значения ячеек, названия книг и листов и пути к файлам в журнал не попадают: вместо них записываются длина и короткий хеш. Сообщения об ошибках от Excel и других компонентов записываются как есть, поэтому просмотрите файл перед публикацией в открытом обращении.
