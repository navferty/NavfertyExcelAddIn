Checklist for validating Excel files before sending

A short list of checks to run on a workbook before it leaves your computer.

Most embarrassing workbook mistakes are discovered by the recipient. These checks take about ten minutes and cover the common ones.

Content

  • No error values anywhere (how to find them).
  • Totals agree with an independent number: the source system, a pivot table or a quick estimate.
  • Calculation mode is Automatic and you pressed F9 once.
  • No numbers stored as text, no stray spaces in keys (text numbers, spaces).
  • Duplicates in key columns have been reviewed.
  • Dates are right: the year, the day/month order, and the period named in the title.
  • Units and currency are written near the numbers.
  • Spelling checked (F7), including sheet names and chart titles.

Hidden things

  • Hidden sheets, rows and columns: do you want the recipient to see them? Right-click a sheet tab to see if Unhide is active.
  • File → Info → Check for Issues → Inspect Document finds comments, hidden content, document properties and personal information.
  • Comments and notes that were meant for you only.
  • Tracked changes and old versions in the file history.
  • Author name and path in the properties.

Links and data sources

  • Data → Edit Links: a workbook linked to files on your drive shows a security warning on the recipient's side and displays old values. Break the links or paste values.
  • Pivot tables are refreshed.
  • If you send a report, think about whether formulas that reference other files should stay as formulas.

Confidential data

  • Columns the recipient does not need (salaries, personal data, margins) are deleted, not just hidden.
  • If you sent the file with sheet protection, remember it is not security. Use encryption with a password for sensitive files, and send the password by another channel.
  • Pivot caches can contain the whole source data even when the pivot shows only a summary.

Presentation

  • Print preview: page orientation, scale, print area, repeated header rows.
  • The active sheet, selected cell and scroll position are on the first cell of the first sheet (Ctrl+Home on each sheet before saving).
  • Column widths are enough to show numbers without ####.
  • Freeze panes on large tables.

File

  • File name tells what it is and when: Sales_2024-03_v2.xlsx.
  • File size is reasonable (see speeding up workbooks).
  • If the recipient may use a different system, think about whether a PDF or CSV is a better format.
  • If the file will be imported by a program, run it through the checks in preparing files for import.

Чек-лист проверки файла Excel перед отправкой

Короткий список проверок, которые стоит выполнить, прежде чем книга уйдёт с вашего компьютера.

Большинство неловких ошибок в книгах обнаруживает получатель. Эти проверки занимают около десяти минут и покрывают самые частые из них.

Содержимое

  • Нигде нет значений-ошибок (как их найти).
  • Итоги совпадают с независимым числом: из исходной системы, сводной таблицы или быстрой оценки.
  • Режим вычислений – Автоматический, и вы один раз нажали F9.
  • Нет чисел-как-текст и лишних пробелов в ключах (числа-как-текст, пробелы).
  • Дубликаты в ключевых столбцах просмотрены.
  • Даты верны: год, порядок дня и месяца, период, указанный в заголовке.
  • Единицы измерения и валюта указаны рядом с числами.
  • Орфография проверена (F7), включая названия листов и заголовки диаграмм.

Скрытое

  • Скрытые листы, строки и столбцы: хотите ли вы, чтобы получатель их увидел? Щёлкните правой кнопкой по ярлыку листа и посмотрите, активно ли Показать.
  • Файл → Сведения → Поиск проблем → Инспектор документов находит примечания, скрытое содержимое, свойства документа и личные данные.
  • Примечания и заметки, предназначавшиеся только вам.
  • Отслеживаемые изменения и старые версии в истории файла.
  • Имя автора и путь в свойствах.

Ссылки и источники данных

  • Данные → Изменить связи: книга со связями на файлы на вашем диске у получателя покажет предупреждение безопасности и отобразит старые значения. Разорвите связи или вставьте значения.
  • Сводные таблицы обновлены.
  • Если вы отправляете отчёт, подумайте, должны ли формулы, ссылающиеся на другие файлы, остаться формулами.

Конфиденциальные данные

  • Столбцы, не нужные получателю (зарплаты, персональные данные, маржа), удалены, а не просто скрыты.
  • Если вы отправили файл с защитой листа, помните, что это не безопасность. Для чувствительных файлов используйте шифрование с паролем, а пароль передайте другим каналом.
  • Кэши сводных таблиц могут содержать все исходные данные, даже если сводная показывает только итоги.

Оформление

  • Предварительный просмотр печати: ориентация страницы, масштаб, область печати, повторяющиеся строки заголовков.
  • Активный лист, выделенная ячейка и позиция прокрутки – на первой ячейке первого листа (перед сохранением нажмите Ctrl+Home на каждом листе).
  • Ширины столбцов достаточно, чтобы числа отображались без ####.
  • Закрепление областей в больших таблицах.

Файл

  • Имя файла говорит, что это и когда: Продажи_2024-03_v2.xlsx.
  • Размер файла разумный (см. ускорение книг).
  • Если у получателя может быть другая система, подумайте, не лучше ли отправить PDF или CSV.
  • Если файл будет импортироваться программой, пройдите проверки из статьи подготовка файлов к импорту.
