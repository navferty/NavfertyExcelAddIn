Converting text numbers to numeric values

Why numbers become text in Excel and several ways to convert them back.

Numbers copied from a web page, a PDF, an accounting system or a CSV often arrive as text. They look normal, but SUM ignores them, sorting puts 100 before 20, and VLOOKUP refuses to match them with real numbers.

How to recognise text numbers

  • They are left-aligned by default while real numbers are right-aligned.
  • A small green triangle appears in the corner of the cell.
  • The status bar shows only Count for the selection, not Sum.
  • =ISNUMBER(A1) returns FALSE.

Quick fixes in Excel

The green triangle. Select the cells, click the warning icon that appears and choose Convert to Number. It works only when Excel flags the cells.

Paste Special. Type 1 in an empty cell and copy it. Select the text numbers, choose Paste Special → Multiply. Excel has to do arithmetic on each value, so it converts them.

Text to Columns. Select one column, open Data → Text to Columns and click Finish right away. This re-parses the values and converts numbers and dates. It is a fast trick for a single column.

A formula. =VALUE(A1) or the shorter =--A1 returns a number. If the source has odd spaces, combine it with cleaning: =VALUE(TRIM(SUBSTITUTE(A1,CHAR(160),""))). Non-breaking spaces (CHAR(160)) are common in data from websites and thousand separators in Russian or French formats, and TRIM does not remove them.

Things that go wrong

  • Decimal separator. 1,5 is text on a system that expects 1.5. Replace the separator first, or use NUMBERVALUE(A1, ",", " ") to state the decimal and group separators explicitly.
  • Leading apostrophe. It is invisible in the cell but marks it as text. Paste Special → Multiply handles it.
  • Minus at the end. Some systems export negative numbers as 100-. Convert with =IF(RIGHT(A1)="-",-LEFT(A1,LEN(A1)-1),A1).
  • Leading zeros. Phone numbers, postal codes and product codes should stay text. Converting them removes the zeros for good, so check before you convert a whole column.
  • Cell format. Changing a cell's format to Number does not convert what is already inside. You need to re-enter the value (F2, Enter) or use one of the methods above.

With the add-in

The Parse Numerics command converts the selected text cells to numbers in one step, including the cases with non-breaking spaces. If the result is wrong, Undo Last Action restores the previous values.

Преобразование чисел-как-текст в числа

Почему числа в Excel становятся текстом и несколько способов вернуть им числовой тип.

Числа, скопированные с веб-страницы, из PDF, учётной системы или CSV, часто приходят как текст. Выглядят они нормально, но СУММ их игнорирует, при сортировке 100 оказывается перед 20, а ВПР отказывается сопоставлять их с настоящими числами.

Как распознать числа-как-текст

  • Они выровнены по левому краю, тогда как настоящие числа по правому.
  • В углу ячейки виден зелёный треугольник.
  • В строке состояния для выделения показывается только Количество, но нет Суммы.
  • =ЕЧИСЛО(A1) возвращает ЛОЖЬ.

Быстрые способы в Excel

Зелёный треугольник. Выделите ячейки, нажмите на появившийся значок предупреждения и выберите Преобразовать в число. Работает только там, где Excel сам пометил ячейки.

Специальная вставка. Введите 1 в пустую ячейку и скопируйте её. Выделите числа-как-текст и выберите Специальная вставка → Умножить. Excel вынужден выполнить арифметику над каждым значением, и оно преобразуется.

Текст по столбцам. Выделите один столбец, откройте Данные → Текст по столбцам и сразу нажмите Готово. Значения будут разобраны заново, числа и даты преобразуются. Быстрый приём для одного столбца.

Формула. =ЗНАЧЕН(A1) или короче =--A1 вернёт число. Если в исходных данных странные пробелы, добавьте очистку: =ЗНАЧЕН(СЖПРОБЕЛЫ(ПОДСТАВИТЬ(A1;СИМВОЛ(160);""))). Неразрывные пробелы (СИМВОЛ(160)) часто встречаются в данных с сайтов и в разделителях разрядов, а СЖПРОБЕЛЫ их не удаляет.

Что может пойти не так

  • Десятичный разделитель. 1,5 – это текст в системе, ожидающей 1.5. Сначала замените разделитель или используйте ЧЗНАЧ(A1; ","; " "), где десятичный разделитель и разделитель групп заданы явно.
  • Апостроф в начале. В ячейке его не видно, но он помечает значение как текст. Справится «Специальная вставка → Умножить».
  • Минус в конце. Некоторые системы выгружают отрицательные числа как 100-. Преобразуйте так: =ЕСЛИ(ПРАВСИМВ(A1)="-";-ЛЕВСИМВ(A1;ДЛСТР(A1)-1);A1).
  • Ведущие нули. Телефоны, индексы и коды товаров должны остаться текстом. После преобразования нули пропадут безвозвратно, так что проверьте столбец до того, как преобразовывать его целиком.
  • Формат ячейки. Смена формата на «Числовой» не преобразует то, что уже внутри. Нужно заново ввести значение (F2, Enter) или применить один из способов выше.

С надстройкой

Команда Преобразовать в числа (Parse Numerics) за один шаг превращает выделенные текстовые ячейки в числа, в том числе с неразрывными пробелами. Если результат не устроил, Отменить последнее действие вернёт прежние значения.
