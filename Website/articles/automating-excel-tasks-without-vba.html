Automating routine Excel tasks without VBA

Tables, Power Query, Flash Fill, dynamic arrays and other built-in tools that replace most simple macros.

Macros are powerful, but they need maintenance, they get blocked by security settings, and they do not run in Excel for the web. A lot of routine work can be done with built-in features that anyone can inspect and change.

Tables

A table (Ctrl+T) extends formulas, formatting, filters and chart ranges automatically when you add rows. This alone removes many “update the range” macros.

Power Query

Data → Get Data is the right tool for repeated imports and clean-up: combine all files from a folder, remove columns, change types, split, unpivot, merge two tables on a key. Every step is recorded. Next month you drop in the new file and click Refresh All.

Typical cases: a monthly export from an accounting system with the same layout; a folder of branch reports to stack into one table; a report that needs unpivoting from a wide to a long format.

Dynamic array functions

In Microsoft 365 and Excel 2021 and later, one formula can return a whole range:

  • =UNIQUE(A2:A1000) – a list of distinct values.
  • =SORT(A2:C1000, 2, -1) – sorted copy of the data.
  • =FILTER(A2:C1000, C2:C1000>1000) – only the rows that match.
  • =XLOOKUP(E2, A:A, C:C, "not found") – a lookup with a default value.
  • =TEXTSPLIT, =TEXTJOIN, =LET to split, join and name intermediate results.

Flash Fill

Type the result for the first row (for example the initials extracted from a full name), then press Ctrl+E. Excel infers the pattern. It is not a formula, so it does not update when the source changes.

Pivot tables and slicers

A pivot table replaces most hand-written summary formulas, and refreshes with a click. Add slicers for interactive filters.

Data validation and conditional formatting

Dropdown lists and rules that highlight problems (an empty required field, a date in the past, a duplicate) prevent errors at entry time, so there is less to clean afterwards.

Office Scripts and Power Automate

For Excel on the web, Office Scripts (TypeScript) can automate edits, and Power Automate can run them on a schedule or when a file arrives. This is a closer replacement for VBA in a cloud workflow.

Add-ins for repeated chores

Small operations that appear in many files, such as trimming text, converting text to numbers, highlighting duplicates or exporting to another format, fit well in an add-in with a ribbon button. See free add-ins.

When VBA still makes sense

When you need custom dialogs, interaction with other desktop applications, or logic that does not fit a formula or a query, VBA is still the straightforward way. The VBA articles linked from the article index may help there.

Автоматизация рутины в Excel без VBA

Таблицы, Power Query, мгновенное заполнение, динамические массивы и другие встроенные инструменты, заменяющие большинство простых макросов.

Макросы мощны, но их нужно поддерживать, их блокируют настройки безопасности, и они не работают в Excel для веба. Многую рутину можно сделать встроенными средствами, которые любой может изучить и изменить.

Таблицы

Таблица (Ctrl+T) автоматически расширяет формулы, форматирование, фильтры и диапазоны диаграмм при добавлении строк. Одно это избавляет от множества макросов «обновить диапазон».

Power Query

Данные → Получить данные – правильный инструмент для регулярных загрузок и очистки: объединить все файлы из папки, удалить столбцы, сменить типы, разделить, развернуть (unpivot), слить две таблицы по ключу. Каждый шаг записывается. В следующем месяце вы кладёте новый файл и нажимаете Обновить всё.

Типичные случаи: ежемесячная выгрузка из бухгалтерской системы с одинаковым макетом; папка с отчётами филиалов, которые надо собрать в одну таблицу; отчёт, который нужно развернуть из широкого формата в длинный.

Функции динамических массивов

В Microsoft 365 и Excel 2021 и новее одна формула может вернуть целый диапазон:

  • =УНИК(A2:A1000) – список уникальных значений.
  • =СОРТ(A2:C1000; 2; -1) – отсортированная копия данных.
  • =ФИЛЬТР(A2:C1000; C2:C1000>1000) – только подходящие строки.
  • =ПРОСМОТРX(E2; A:A; C:C; "не найдено") – поиск со значением по умолчанию.
  • =ТЕКСТРАЗД, =ОБЪЕДИНИТЬ, =LET – разбить, склеить и дать имена промежуточным результатам.

Мгновенное заполнение

Введите результат для первой строки (например, инициалы из полного имени) и нажмите Ctrl+E. Excel угадает шаблон. Это не формула, поэтому при изменении источника результат не обновляется.

Сводные таблицы и срезы

Сводная таблица заменяет большинство самодельных итоговых формул и обновляется одним щелчком. Добавьте срезы для интерактивных фильтров.

Проверка данных и условное форматирование

Выпадающие списки и правила, подсвечивающие проблемы (пустое обязательное поле, дата в прошлом, дубликат), предотвращают ошибки при вводе, так что потом меньше надо чистить.

Office Scripts и Power Automate

Для Excel в вебе сценарии Office Scripts (TypeScript) автоматизируют правки, а Power Automate может запускать их по расписанию или при поступлении файла. Это более близкая замена VBA в облачном процессе.

Надстройки для повторяющихся мелочей

Небольшие операции, которые встречаются во многих файлах, – обрезка текста, преобразование текста в числа, подсветка дубликатов или экспорт в другой формат – удобно вынести в надстройку с кнопкой на ленте. См. бесплатные надстройки.

Когда VBA всё ещё уместен

Если нужны собственные диалоги, взаимодействие с другими настольными приложениями или логика, которая не укладывается в формулу или запрос, VBA остаётся прямым путём. Статьи про VBA из списка статей могут помочь.
