How to speed up large Excel workbooks

Why a workbook becomes slow and what to change first.

A workbook that takes a minute to open or freezes on every edit has usually one or two clear causes. Find those before trying everything.

Measure first

Switch to manual calculation (Formulas → Calculation Options → Manual). If the file becomes responsive, formulas are the issue. If it is still slow, look at file size, formatting, objects and add-ins. Press F9 to calculate manually. Remember to switch back, or tell whoever uses the file.

Formulas

  • Whole-column references in heavy functions. SUMIFS on A:A is OK in modern Excel, but array formulas and SUMPRODUCT over entire columns are slow. Limit ranges or use tables.
  • Thousands of VLOOKUPs with exact match over a large range. Sort the data and use binary search where it makes sense, or add one helper column with MATCH and reuse its result with INDEX. XLOOKUP and a lookup against a proper table are also faster than repeating the same search in many columns.
  • Volatile functions (NOW, TODAY, RAND, OFFSET, INDIRECT) recalculate on every change and everything that depends on them too. Replace OFFSET and INDIRECT with INDEX or table references where you can.
  • Formulas that never change. Old months in a report do not need to be calculated each time. Paste them as values and keep a copy of the formulas somewhere.
  • Chains of dependency across many sheets and external links. Check Data → Edit Links and remove links to files that no longer exist.

File size

  • Used range that is much bigger than the data. Press Ctrl+End. If it jumps far beyond your data, select the empty rows and columns below and to the right, delete them (not just clear), and save.
  • Formatting applied to entire columns or rows that were then filled with fancy conditional formatting. Check Conditional Formatting → Manage Rules and delete duplicates.
  • Images and shapes. Compress pictures (Picture Format → Compress Pictures) and delete invisible shapes. Home → Find & Select → Selection Pane lists all objects, including hidden ones.
  • Pivot caches. Each pivot table may carry a copy of the data. Use the same cache for pivots built on the same source, and untick Save source data with file where acceptable.
  • Format. Saving as .xlsb (binary workbook) is usually smaller and opens faster than .xlsx. The trade-off is that some non-Microsoft tools cannot read it.

Environment

  • Use 64-bit Excel if you work with very large data sets.
  • Disable add-ins you do not use (File → Options → Add-ins) and check whether the file is slow without them.
  • Files on network drives open slowly; copy locally to test.

When Excel is the wrong place

If a workbook holds millions of rows or many joins, move the data to a database and use Excel for reports on top of it. Power Query with the data model, or a SQLite or other database file, handles volumes where formulas do not. See exporting to SQLite.

Как ускорить большие книги Excel

Почему книга тормозит и что менять в первую очередь.

У книги, которая открывается минуту или зависает при каждой правке, обычно одна-две понятные причины. Найдите их, прежде чем пробовать всё подряд.

Сначала измерьте

Переключитесь на ручной расчёт (Формулы → Параметры вычислений → Вручную). Если файл ожил, дело в формулах. Если всё ещё тормозит, смотрите на размер файла, форматирование, объекты и надстройки. Для ручного пересчёта нажмите F9. Не забудьте вернуть режим обратно или предупредите тех, кто пользуется файлом.

Формулы

  • Ссылки на целые столбцы в тяжёлых функциях. СУММЕСЛИМН по A:A в современном Excel нормально, но формулы массива и СУММПРОИЗВ по целым столбцам медленны. Ограничьте диапазоны или используйте таблицы.
  • Тысячи ВПР с точным совпадением по большому диапазону. Отсортируйте данные и используйте бинарный поиск там, где это уместно, или добавьте один вспомогательный столбец с ПОИСКПОЗ и используйте его результат в ИНДЕКС. ПРОСМОТРX и поиск по нормальной таблице тоже быстрее, чем один и тот же поиск, повторённый во многих столбцах.
  • Волатильные функции (ТДАТА, СЕГОДНЯ, СЛЧИС, СМЕЩ, ДВССЫЛ) пересчитываются при любом изменении вместе со всем, что от них зависит. Заменяйте СМЕЩ и ДВССЫЛ на ИНДЕКС или ссылки на таблицы, где возможно.
  • Формулы, которые никогда не меняются. Старые месяцы в отчёте не нужно пересчитывать каждый раз. Вставьте их как значения, а копию формул храните отдельно.
  • Цепочки зависимостей через много листов и внешние ссылки. Проверьте Данные → Изменить связи и удалите ссылки на файлы, которых больше нет.

Размер файла

  • Используемый диапазон намного больше данных. Нажмите Ctrl+End. Если курсор улетает далеко за пределы данных, выделите пустые строки ниже и столбцы справа, удалите их (именно удалите, а не очистите) и сохраните.
  • Форматирование, применённое к целым столбцам или строкам, плюс обилие условного форматирования. Откройте Условное форматирование → Управление правилами и удалите дубликаты.
  • Изображения и фигуры. Сожмите рисунки (Формат рисунка → Сжать рисунки) и удалите невидимые фигуры. Главная → Найти и выделить → Область выделения показывает все объекты, в том числе скрытые.
  • Кэши сводных таблиц. Каждая сводная может нести копию данных. Используйте один кэш для сводных на одном источнике и, где допустимо, снимите галочку Сохранять исходные данные вместе с файлом.
  • Формат. Сохранение как .xlsb (двоичная книга) обычно даёт файл меньше и быстрее открываемый, чем .xlsx. Платой служит то, что некоторые сторонние инструменты его не читают.

Окружение

  • Для очень больших объёмов данных используйте 64-разрядный Excel.
  • Отключите ненужные надстройки (Файл → Параметры → Надстройки) и проверьте, тормозит ли файл без них.
  • Файлы на сетевых дисках открываются медленно; для проверки скопируйте файл локально.

Когда Excel – не то место

Если в книге миллионы строк или много объединений, перенесите данные в базу и используйте Excel для отчётов поверх неё. Power Query с моделью данных или файл SQLite либо другой базы справляются с объёмами, перед которыми формулы пасуют. См. экспорт в SQLite.
