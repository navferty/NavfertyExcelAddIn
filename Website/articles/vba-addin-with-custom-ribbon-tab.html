Creating a VBA add-in with its own ribbon tab (Russian)

A tutorial on packaging macros into an .xlam add-in with a custom Excel ribbon tab. Original article in Russian.

Macros in one workbook are not available in another, and a personal macro workbook is awkward to share. An .xlam add-in solves this: it loads with Excel, and its procedures are available everywhere, and a custom ribbon tab gives them buttons.

The author's step-by-step tutorial in Russian covers building such an add-in, from saving the workbook as .xlam to adding a separate tab using the Custom UI XML:

Tutorial: creating a VBA add-in with a separate tab in MS Excel (Pikabu, Russian)

In short

  1. Write the procedures in a normal workbook, in a standard module.
  2. Save as Excel Add-In (*.xlam).
  3. Add a customUI14.xml part to the file, which describes the tab, groups and buttons, with an onAction callback name for each button.
  4. In VBA, write a procedure with a matching name and signature for each callback: Sub OnButtonClick(control As IRibbonControl).
  5. Load it with File → Options → Add-ins → Go → Browse.

The Custom UI Editor for Microsoft Office is a free tool that helps with the XML part.

Создание VBA-надстройки с отдельной вкладкой в Excel

Руководство по упаковке макросов в надстройку .xlam с собственной вкладкой на ленте Excel.

Макросы из одной книги недоступны в другой, а личную книгу макросов неудобно передавать. Надстройка .xlam решает это: она загружается вместе с Excel, её процедуры доступны везде, а собственная вкладка на ленте даёт им кнопки.

Подробное пошаговое руководство автора на Pikabu описывает создание такой надстройки: от сохранения книги в .xlam до добавления отдельной вкладки через Custom UI XML:

Туториал: создание VBA-надстройки с отдельной вкладкой в MS Excel (Pikabu)

Вкратце

  1. Напишите процедуры в обычной книге, в стандартном модуле.
  2. Сохраните как Надстройка Excel (*.xlam).
  3. Добавьте в файл часть customUI14.xml, описывающую вкладку, группы и кнопки, с именем callback в onAction для каждой кнопки.
  4. В VBA напишите для каждого callback процедуру с совпадающим именем и сигнатурой: Sub OnButtonClick(control As IRibbonControl).
  5. Подключите через Файл → Параметры → Надстройки → Перейти → Обзор.

Бесплатная программа Custom UI Editor for Microsoft Office помогает с XML-частью.
