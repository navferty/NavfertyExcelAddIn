Pivot tables in Excel: a practical introduction

How to build a first pivot table, summarise by category and by date, switch between sum and count, and keep it up to date.

A pivot table summarises a long list without a single formula: totals by category, counts, averages, by month or year. It is worth learning because the same task with SUMIFS means a formula for every cell. This article covers the basics only; the feature is deep, and the Microsoft documentation goes further.

Prepare the source data

A pivot table needs a flat list: one header row, one record per row, no empty rows or columns, no merged cells, no subtotals inside. The example below has four columns: Order Id, Order Date, Department Id and Amount. If the data is messy, see cleaning data first. Dates and amounts must be real dates and numbers, not text (converting text numbers).

It helps to turn the list into a table first (Ctrl+T). A pivot table built on a table picks up new rows after a refresh, and does not include blank rows.

Create the pivot table

Select any cell in the data and choose Insert → PivotTable. Check the range Excel suggests and choose where to put the result; a new worksheet is the safe default.

In this example the range is written as whole columns (SourceData!$A:$D). It works, but the pivot table will then contain a (blank) item for the empty cells below the data. A table or an exact range such as $A$1:$D$25 avoids it.

Build the report

The empty pivot table shows the PivotTable Fields pane. The four areas below the field list decide what goes where:

  • Rows – the values that become row labels.
  • Columns – the values that become column headings.
  • Values – what to calculate (sum, count, average).
  • Filters – a drop-down above the table to limit the whole report.

Drag Department Id to Rows and Amount to Values. This is the first example: total amount per department. Excel chooses Sum for numbers.

Count instead of sum

To count orders per department, click the field in the Values area, choose Value Field Settings and pick Count. Counting works on any column, and for text columns Count is the default. The same dialog has Average, Max, Min and the Show Values As tab with percentages of the total.

Group dates by year or month

Drag Order Date to Columns. In recent versions of Excel the dates are grouped automatically (Years, Quarters, Months fields appear). If they are not, right-click a date and choose Group. Here the report has departments in the rows, years in the columns and the sum of amounts in between:

The grouping only works if every value in the column is a real date. One text value or an empty cell and Excel will not offer it.

Refresh

A pivot table is a snapshot of the data and does not recalculate when the source changes. Right-click it and choose Refresh, or press Alt+F5. Data → Refresh All (Ctrl+Alt+F5) refreshes every pivot table in the workbook.

Limitations to know about

  • You cannot type over the values in the pivot area; the numbers come from the source.
  • New rows are included only if they fall inside the source range, which is the point of using a table.
  • A column format (like a thousands separator) can reset on refresh. Set it through Value Field Settings → Number Format.
  • Read cells from a pivot with GETPIVOTDATA. Excel inserts it for you when you click a pivot cell from a formula; its address-style alternative breaks when the layout changes.

Сводные таблицы в Excel: практическое введение

Как построить первую сводную таблицу, свести данные по категориям и датам, переключаться между суммой и количеством и обновлять результат.

Сводная таблица сворачивает длинный список без единой формулы: итоги по категориям, количество, средние значения, по месяцам или годам. Её стоит освоить, потому что та же задача через СУММЕСЛИМН потребует формулу в каждой ячейке. Здесь только основы; тема большая, и дальше поможет документация Microsoft.

Подготовьте исходные данные

Сводной таблице нужен плоский список: одна строка заголовков, одна запись в строке, без пустых строк и столбцов, без объединённых ячеек и промежуточных итогов внутри. В примере четыре столбца: Order Id, Order Date, Department Id и Amount. Если данные неаккуратные, сначала см. очистку данных. Даты и суммы должны быть настоящими датами и числами, а не текстом (преобразование чисел-как-текст).

Полезно сначала превратить список в таблицу (Ctrl+T). Сводная таблица на основе таблицы подхватывает новые строки при обновлении и не включает пустые.

Создайте сводную таблицу

Выделите любую ячейку данных и выберите Вставка → Сводная таблица. Проверьте предложенный диапазон и выберите, куда поместить результат; безопасный вариант – новый лист.

В примере диапазон задан целыми столбцами (SourceData!$A:$D). Это работает, но в сводной таблице появится элемент (пусто) для пустых ячеек ниже данных. Таблица или точный диапазон вроде $A$1:$D$25 этого избегают.

Постройте отчёт

Пустая сводная таблица показывает панель Поля сводной таблицы. Четыре области под списком полей определяют, что куда попадёт:

  • Строки – значения, которые станут подписями строк.
  • Столбцы – значения, которые станут заголовками столбцов.
  • Значения – что вычислять (сумма, количество, среднее).
  • Фильтры – раскрывающийся список над таблицей, ограничивающий весь отчёт.

Перетащите Department Id в Строки, а Amount в Значения. Это первый пример: общая сумма по подразделениям. Для чисел Excel выбирает Сумму.

Количество вместо суммы

Чтобы посчитать заказы по подразделениям, щёлкните поле в области Значения, выберите Параметры полей значений и укажите Количество. Количество работает для любого столбца, а для текстовых оно используется по умолчанию. В том же диалоге есть среднее, максимум, минимум и вкладка Дополнительные вычисления с долями от итога.

Группировка дат по годам и месяцам

Перетащите Order Date в Столбцы. В современных версиях Excel даты группируются автоматически (появляются поля «Годы», «Кварталы», «Месяцы»). Если этого не произошло, щёлкните дату правой кнопкой и выберите Группировать. В отчёте подразделения в строках, годы в столбцах, а между ними сумма:

Группировка работает только если все значения в столбце являются настоящими датами. Достаточно одного текстового значения или пустой ячейки, и Excel её не предложит.

Обновление

Сводная таблица – это снимок данных, она не пересчитывается при изменении источника. Щёлкните её правой кнопкой и выберите Обновить или нажмите Alt+F5. Данные → Обновить всё (Ctrl+Alt+F5) обновляет все сводные таблицы книги.

Ограничения

  • Значения в области сводной таблицы нельзя перезаписать: числа берутся из источника.
  • Новые строки попадают в отчёт, только если находятся внутри диапазона источника, поэтому и стоит использовать таблицу.
  • Формат столбца (например, разделитель разрядов) может сброситься при обновлении. Задайте его через Параметры полей значений → Числовой формат.
  • Значения из сводной таблицы в формулах читаются функцией ПОЛУЧИТЬ.ДАННЫЕ.СВОДНОЙ.ТАБЛИЦЫ. Excel вставляет её сам, когда вы щёлкаете ячейку сводной таблицы при вводе формулы; обычная ссылка на адрес ломается при изменении макета.
