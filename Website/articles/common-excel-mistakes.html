Common Excel mistakes and how to fix them

Problems that show up again and again in real workbooks, with a way to avoid each one.

Most spreadsheet errors are not complicated. They come from a handful of habits that are easy to change.

Numbers stored as text

Totals that do not add up and lookups that fail often come from text-formatted numbers. See converting text numbers for the fixes.

Hard-coded numbers inside formulas

=B2*1.2 works until the tax rate changes and you have to find every place where 1.2 was typed. Put the rate in a labelled cell and reference it: =B2*$F$1. Name the cell (Formulas → Define Name) and the formula reads =B2*VAT.

Relative and absolute references mixed up

If a formula copied down gives odd results, check the dollar signs. $A$1 never moves, A$1 keeps the row, $A1 keeps the column. F4 cycles through them while editing.

Ranges that do not cover new rows

=SUM(B2:B100) silently misses row 101. Convert the data to a table (Ctrl+T) and use structured references such as =SUM(Sales[Amount]), which grow with the data.

Merged cells in the data area

Merged cells break sorting, filtering, pivot tables and copy-paste. Use Center Across Selection (Format Cells → Alignment → Horizontal) for the visual effect. If you inherited a merged table, unmerge it and fill each cell with the original value.

Dates that are really text

If 01.02.2024 will not sort or calculate, it is text, or it was read with the wrong day/month order. Check with =ISNUMBER(A1). Convert with DATE, DATEVALUE or Text to Columns with the date format set explicitly.

Approximate match in lookups

VLOOKUP(x, range, 2) without the last argument defaults to approximate match and needs sorted data. It can return a wrong value instead of an error. Always write FALSE (or use XLOOKUP where available, which defaults to an exact match).

Hidden rows, columns and sheets

SUM includes hidden rows, SUBTOTAL(109, ...) does not. Filtered rows are the same story: pick the function that matches what you intend. Before you send a file, check Review → Inspect Document or right-click a sheet tab and look at Unhide.

Copying formulas over values and back

Paste Special → Values removes the link to source cells. Sometimes that is intended, but a report where half of the figures are frozen is a trap. Colour inputs differently from formulas, and keep one sheet with the raw data you never touch.

No second pair of eyes

A few cheap checks catch a surprising amount: totals compared with an independent calculation, a count of rows before and after, and Formulas → Show Formulas (Ctrl+`) to look for a cell where a formula was replaced by a number. See also the pre-send checklist.

Типичные ошибки в Excel и как их исправить

Проблемы, которые снова и снова встречаются в реальных книгах, и способ избежать каждой.

Большинство ошибок в таблицах несложные. Они возникают из нескольких привычек, которые легко поменять.

Числа, сохранённые как текст

Итоги, которые не сходятся, и поиск, который не находит, часто связаны с числами в текстовом формате. Способы исправления – в статье преобразование текста в числа.

Числа, вбитые прямо в формулы

=B2*1,2 работает, пока не изменится ставка налога и вам не придётся искать все места, где набрано 1,2. Вынесите ставку в подписанную ячейку и ссылайтесь на неё: =B2*$F$1. Дайте ячейке имя (Формулы → Присвоить имя), и формула станет читаться как =B2*НДС.

Перепутанные относительные и абсолютные ссылки

Если формула, скопированная вниз, даёт странные результаты, проверьте знаки доллара. $A$1 не двигается никогда, A$1 фиксирует строку, $A1 – столбец. При редактировании F4 переключает эти варианты по кругу.

Диапазоны, не охватывающие новые строки

=СУММ(B2:B100) молча пропустит строку 101. Преобразуйте данные в таблицу (Ctrl+T) и используйте структурированные ссылки вида =СУММ(Продажи[Сумма]), они растут вместе с данными.

Объединённые ячейки в области данных

Объединённые ячейки ломают сортировку, фильтры, сводные таблицы и копирование. Для визуального эффекта используйте По центру выделения (Формат ячеек → Выравнивание → По горизонтали). Если вам досталась таблица с объединениями, разъедините ячейки и заполните каждую исходным значением.

Даты, которые на самом деле текст

Если 01.02.2024 не сортируется и не участвует в расчётах, это текст или дата, прочитанная с другим порядком дня и месяца. Проверьте через =ЕЧИСЛО(A1). Преобразуйте через ДАТА, ДАТАЗНАЧ или «Текст по столбцам» с явно заданным форматом даты.

Приблизительное совпадение в поиске

ВПР(x; диапазон; 2) без последнего аргумента по умолчанию использует приблизительное совпадение и требует отсортированных данных. Вместо ошибки она может вернуть неправильное значение. Всегда пишите ЛОЖЬ (или используйте ПРОСМОТРX, где по умолчанию точное совпадение).

Скрытые строки, столбцы и листы

СУММ учитывает скрытые строки, ПРОМЕЖУТОЧНЫЕ.ИТОГИ(109; ...) – нет. С отфильтрованными строками то же самое: выбирайте функцию под то, что имеете в виду. Перед отправкой файла проверьте Файл → Сведения → Поиск проблем → Инспектор документов или щёлкните правой кнопкой по ярлыку листа и посмотрите, активно ли Показать.

Формулы, замещённые значениями, и обратно

«Специальная вставка → Значения» разрывает связь с исходными ячейками. Иногда это нужно, но отчёт, где половина цифр «заморожена», – ловушка. Выделяйте входные данные другим цветом, чем формулы, и храните отдельный лист с исходными данными, которые вы не трогаете.

Нет второй пары глаз

Несколько дешёвых проверок ловят удивительно много: итоги, сверенные с независимым расчётом, число строк до и после, а также Формулы → Показать формулы (Ctrl+`), чтобы найти ячейку, где формулу заменили числом. См. также чек-лист перед отправкой.
