Exporting Excel data to SQLite

When a spreadsheet is no longer enough, SQLite gives you real queries in a single file.

Excel handles a few hundred thousand rows, but joins across sheets, grouping with conditions and repeated lookups get slow and fragile. SQLite is a small database stored in one file, with no server. Many tools can read it: DB Browser for SQLite, DBeaver, Python, R, Power BI and most programming languages.

Why move data there

  • You need a JOIN across several tables instead of nested VLOOKUPs.
  • You want to run the same query repeatedly on a new data set.
  • The workbook has become slow and large.
  • A developer or analyst asks for the data in a format a program can read reliably.

Prepare the sheets

Whatever tool you use, the result is only as good as the input:

  • One header row, one table per sheet, no merged cells and no blank rows or columns in the middle.
  • Unique and non-empty header names. Avoid spaces and special characters if you plan to write SQL by hand.
  • One type per column. A column with mostly numbers and a few n/a strings becomes text.
  • Dates as real dates, not as text.

Other ways to do it

  • Save each sheet as CSV and import it with the .import command of the sqlite3 command-line tool, or with the import dialog in DB Browser for SQLite.
  • Use Python with pandas: pd.read_excel(...).to_sql(...).
  • Connect through ODBC and write the data with VBA. This is flexible and needs the most setup.

With the add-in

Export to SQLite writes the whole workbook to a .db file. Each sheet becomes a table, the column types are detected automatically, and you can choose whether the first row holds the column names and how many leading rows to skip, which helps when a report has a title block above the table.

A first query

Open the file in any SQLite client. If the sheet was called Orders and has columns Customer and Amount:

SELECT Customer, SUM(Amount) AS Total
FROM Orders
GROUP BY Customer
ORDER BY Total DESC;

If a name contains spaces, wrap it in double quotes: "Order date".

Экспорт данных из Excel в SQLite

Когда таблицы уже недостаточно, SQLite даёт полноценные запросы в одном файле.

Excel справляется с несколькими сотнями тысяч строк, но объединения между листами, группировки с условиями и повторяющиеся поиски становятся медленными и хрупкими. SQLite – это небольшая база данных в одном файле, без сервера. Читать её умеют многие инструменты: DB Browser for SQLite, DBeaver, Python, R, Power BI и почти все языки программирования.

Зачем переносить данные туда

  • Нужен JOIN по нескольким таблицам вместо вложенных ВПР.
  • Один и тот же запрос нужно запускать на новых данных.
  • Книга стала медленной и тяжёлой.
  • Разработчик или аналитик просит данные в формате, который программа читает без сюрпризов.

Подготовьте листы

Каким бы инструментом вы ни пользовались, результат не лучше исходных данных:

  • Одна строка заголовков, одна таблица на лист, без объединённых ячеек и пустых строк или столбцов посередине.
  • Уникальные и непустые имена заголовков. Если собираетесь писать SQL вручную, избегайте пробелов и спецсимволов.
  • Один тип на столбец. Столбец с числами и несколькими строками «н/д» станет текстовым.
  • Даты – настоящие даты, а не текст.

Другие способы

  • Сохраните каждый лист как CSV и импортируйте командой .import в консольной утилите sqlite3 или через диалог импорта в DB Browser for SQLite.
  • Используйте Python с pandas: pd.read_excel(...).to_sql(...).
  • Подключитесь через ODBC и запишите данные из VBA. Это гибко, но требует больше всего настройки.

С надстройкой

Команда Экспорт в SQLite записывает всю книгу в файл .db. Каждый лист становится таблицей, типы столбцов определяются автоматически, а ещё можно указать, содержит ли первая строка имена столбцов, и сколько начальных строк пропустить – это удобно, когда над таблицей есть блок с заголовком отчёта.

Первый запрос

Откройте файл в любом клиенте SQLite. Пусть лист называется Orders и содержит столбцы Customer и Amount:

SELECT Customer, SUM(Amount) AS Total
FROM Orders
GROUP BY Customer
ORDER BY Total DESC;

Если в имени есть пробелы, возьмите его в двойные кавычки: "Order date".
