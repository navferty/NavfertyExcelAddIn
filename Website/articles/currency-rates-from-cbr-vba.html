Currency exchange rates from the Bank of Russia in VBA with auto-refresh (Russian)

A VBA example: loading currency rates from the CBR website into Excel and refreshing them automatically. Original article in Russian.

Financial workbooks often need the official exchange rate for a given date. Typing it in by hand every day is error-prone. The Bank of Russia publishes daily rates in a machine-readable form, so a macro can fetch them.

The author's article in Russian shows how to load the rates with VBA and refresh them on a schedule when the workbook is opened:

Currency rates from the CBR website in VBA with auto-refresh (Pikabu, Russian)

The idea

  • Send an HTTP request to the CBR daily XML service with MSXML2.XMLHTTP, passing the date.
  • Parse the XML response with MSXML2.DOMDocument and read each currency's code and value.
  • Write the values to a sheet and, if required, use Application.OnTime to run it again later.
  • Convert the decimal comma in the response to the decimal separator of the current locale before writing numbers.

The same task is available inside the add-in: Navferty's Excel Add-In has a currency exchange rates dialog with several providers, including the Bank of Russia, the European Central Bank and the National Bank of Ukraine.
