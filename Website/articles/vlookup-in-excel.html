VLOOKUP in Excel: syntax, examples and common errors

How VLOOKUP works, a worked example with orders and users, why it returns #N/A, and what to use instead.

A typical situation: one sheet has orders with a user id, another has a list of users, and you want the user name next to each order. Copying names by hand does not scale. VLOOKUP (in Russian Excel, ВПР) does this: it takes a key, finds it in the first column of a table and returns a value from the same row.

Syntax

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
  • lookup_value – what to find, for example the user id in the current row.
  • table_array – where to look. The key must be in the first column of this range.
  • col_index_num – which column of the range to return, counting from 1.
  • range_lookup – FALSE (or 0) for an exact match, TRUE for an approximate one. If omitted, Excel uses TRUE, which is rarely what you want for ids and names.

An example

In cell E2 of the Orders sheet start the formula. After typing the first argument, switch to the Users sheet and select the columns A:B; Excel fills in the second argument:

=VLOOKUP(D2, Users!A:B, 2, FALSE)

Here the key is in D2, the table is Users!A:B, and we return the second column (the name). Copy the formula down:

The order with user id 8 shows #N/A: there is no such id in the Users sheet. This is the correct behaviour. It tells you the data does not match, which is often exactly what you are looking for.

Why you get #N/A (or a wrong value)

  • The key is really missing. Check the reference list.
  • Text versus number. The id 1 as a number does not match "1" as text. See converting text numbers to numeric values.
  • Extra spaces. "John " is not "John". See removing extra spaces.
  • The key column is not first. VLOOKUP only looks to the right of the first column of table_array.
  • Approximate match. Without FALSE Excel assumes the first column is sorted and can quietly return a wrong row. Always write the last argument.
  • Hard-coded column number. If someone inserts a column in the lookup table, 2 now points at the wrong one. Check formulas after changing the table structure.
  • A moving range. When you copy the formula, A2:B6 shifts too. Use whole columns (A:B) or lock the range ($A$2:$B$6).

Alternatives

XLOOKUP (Excel 2021 and Microsoft 365) removes most of these limits: exact match by default, no column number, can look to the left, and has a built-in "not found" value.

=XLOOKUP(D2, Users!A:A, Users!B:B, "not found")

INDEX and MATCH work in every version and also look in any direction:

=INDEX(Users!B:B, MATCH(D2, Users!A:A, 0))

If the lookup list is a table (see cleaning data), you can refer to its columns by name, and the range grows when you add rows.

A formula like IFERROR(VLOOKUP(...), "") hides the errors, including real data problems. Use it only after you have checked why the values are missing.

ВПР (VLOOKUP) в Excel: синтаксис, примеры и частые ошибки

Как работает ВПР, пример с заказами и пользователями, почему функция возвращает #N/A и чем её можно заменить.

Типичная ситуация: на одном листе заказы с идентификатором пользователя, на другом список пользователей, и нужно подставить имя рядом с каждым заказом. Копировать вручную долго и ненадёжно. Это делает ВПР (в английской версии VLOOKUP): берёт ключ, ищет его в первом столбце таблицы и возвращает значение из той же строки.

Синтаксис

=ВПР(искомое_значение; таблица; номер_столбца; [интервальный_просмотр])
  • искомое_значение – что искать, например идентификатор пользователя в текущей строке.
  • таблица – где искать. Ключ должен быть в первом столбце этого диапазона.
  • номер_столбца – какой столбец диапазона вернуть, считая с 1.
  • интервальный_просмотр – ЛОЖЬ (или 0) для точного совпадения, ИСТИНА для приблизительного. Если аргумент опущен, Excel использует ИСТИНА, а для идентификаторов и имён это почти всегда не то, что нужно.

Пример

На листе Orders находятся номер заказа, дата, сумма и идентификатор пользователя:

На листе Users справочник:

В ячейке E2 листа Orders начните формулу. Введя первый аргумент, перейдите на лист Users и выделите столбцы A:B, Excel подставит второй аргумент:

=ВПР(D2; Users!A:B; 2; ЛОЖЬ)

Ключ находится в D2, таблица – Users!A:B, возвращаем второй столбец (имя). Протяните формулу вниз:

В заказе с идентификатором 8 появился #Н/Д: такого идентификатора нет на листе Users. Это правильное поведение: оно сообщает, что данные не сходятся, а это часто как раз то, что нужно найти.

Почему появляется #Н/Д (или неверное значение)

  • Ключа действительно нет. Проверьте справочник.
  • Текст и число. Число 1 не совпадает с текстом "1". См. преобразование чисел-как-текст.
  • Лишние пробелы. "Иван " не равно "Иван". См. удаление лишних пробелов.
  • Столбец с ключом не первый. ВПР ищет только справа от первого столбца диапазона.
  • Приблизительное совпадение. Без ЛОЖЬ Excel считает, что первый столбец отсортирован, и может молча вернуть не ту строку. Всегда указывайте последний аргумент.
  • Номер столбца задан числом. Если в справочник вставили столбец, 2 теперь указывает не туда. После изменения структуры таблицы проверяйте формулы.
  • Диапазон «уезжает». При копировании формулы A2:B6 тоже смещается. Используйте столбцы целиком (A:B) или закрепите диапазон ($A$2:$B$6).

Альтернативы

ПРОСМОТРX (XLOOKUP, Excel 2021 и Microsoft 365) снимает большинство этих ограничений: точное совпадение по умолчанию, не нужен номер столбца, можно искать влево, есть значение на случай «не найдено».

=ПРОСМОТРX(D2; Users!A:A; Users!B:B; "не найдено")

ИНДЕКС и ПОИСКПОЗ работают во всех версиях и тоже ищут в любом направлении:

=ИНДЕКС(Users!B:B; ПОИСКПОЗ(D2; Users!A:A; 0))

Если справочник оформлен как таблица (см. очистку данных), на её столбцы можно ссылаться по имени, а диапазон растёт при добавлении строк.

Конструкция ЕСЛИОШИБКА(ВПР(...); "") скрывает ошибки, в том числе настоящие проблемы с данными. Применяйте её после того, как выяснили, почему значения не находятся.
