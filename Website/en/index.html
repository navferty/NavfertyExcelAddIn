Commands

Everything on the Navferty's Tools ribbon tab. Open a command to see what it does with before/after screenshots.

Clean up text and numbers

Parse NumericsTurns numbers stored as text into real numbers. Trim SpacesRemoves extra spaces and line breaks from text cells. Toggle CaseCycles text between Abc, abc and ABC. Unmerge CellsUnmerges cells and fills each one with the original value. Conditional FormattingFills conditional formatting across the whole table, based on the first row.

Letters and number formats

ReplaceTransliterates Cyrillic or swaps look-alike letters for Latin ones. Stringify NumericsWrites numbers in words in Russian, English or French.

Find problems in data

Find All Cells Containing ErrorsLists every formula error in the selection and jumps to it. Highlight DuplicationsColours repeated values, one colour per group. Validate ValuesChecks values as numbers, dates, TIN or XML-safe text.

Export, XML and protection

Copy as MarkdownCopies the selected cells as a Markdown table. Export to SQLiteSaves the whole workbook as a SQLite database. Create Sample XML based on XSDBuilds a sample XML file from an XSD schema. Validate XML with XSDChecks an XML file against an XSD and reports errors in a sheet. Unprotect WorkbookRemoves protection from sheets, structure and VBA projects. Worksheets ProtectionProtects or unprotects many worksheets at once. Undo Last ActionReverts the last change made by the add-in.

More tools

Sheet TabsShows or hides the worksheet tabs. Reference Style (A1/R1C1)Switches formula references between A1 and R1C1 style. Exchange ratesPicks a currency rate from an online source and pastes it into the cell.
