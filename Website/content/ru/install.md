## Установка сертификата (если требуется)

<div class="warning-box">

Если возникает предупреждение о сертификате:

1.  Щёлкните правой кнопкой мыши по файлу `setup.exe` и выберите **Свойства**
2.  Перейдите на вкладку **Цифровые подписи**
3.  Выберите подпись и нажмите **Сведения**
4.  Нажмите **Просмотреть сертификат** → **Установить сертификат**
5.  Выберите **Локальный компьютер** и поместите его в **Доверенные корневые центры сертификации**

<img src="/cert-install.png" loading="lazy" width="1195" height="604" alt="Мастер импорта сертификатов" />

*Сертификат можно удалить после установки, но он потребуется для будущих обновлений.*

## Офлайн-установка

Каждый релиз собирается в GitHub Actions, и полный набор установочных файлов прикреплён к нему:

1.  Откройте <a href="https://github.com/navferty/NavfertyExcelAddIn/releases/latest" rel="noopener" target="_blank">последний релиз</a>
2.  Скачайте прикреплённый архив `NavfertyExcelAddIn-*.zip`
3.  Распакуйте файлы в папку и запустите файл `.vsto`

Excel сохраняет расположение запущенного файла `.vsto` и использует его для проверки обновлений. Создайте отдельную папку для надстройки, храните в ней распакованные файлы установки и используйте эту же папку при установке будущих обновлений.

<img src="/images/offline-install-addin-location-ru.png" loading="lazy" width="1012" height="530" alt="Окно надстроек COM в Excel с расположением файла надстройки" />

После установки перезапустите Excel. На ленте появится новая вкладка **Navferty's Tools**.

## Удаление

**Способ 1: Параметры Windows (рекомендуется)**

1.  Откройте Параметры Windows (<span class="kbd">Win</span> + <span class="kbd">I</span>)
2.  Перейдите в **Приложения** → **Установленные приложения** (в Windows 10: **Приложения и возможности**)
3.  Найдите **Navferty Excel Add-In** в списке
4.  Нажмите **Удалить** и следуйте инструкциям

**Способ 2: Панель управления**

1.  Откройте **Панель управления**
2.  Перейдите в **Программы** → **Программы и компоненты**
3.  Щёлкните правой кнопкой мыши по **Navferty Excel Add-In** и выберите **Удалить**
