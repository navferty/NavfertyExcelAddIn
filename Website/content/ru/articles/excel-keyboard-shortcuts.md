# Горячие клавиши Excel, которые экономят больше всего времени

Практичный набор горячих клавиш Excel для редактирования, навигации, выделения, заполнения и вставки, сгруппированный по задачам.

Основная экономия времени при работе с клавиатуры приходится на небольшой набор сочетаний, которыми пользуешься постоянно. Они сгруппированы по задачам. Выберите несколько из одной группы, поработайте с ними неделю, потом добавьте следующие.

## Редактирование ячейки

- <span class="kbd">F2</span> – редактировать ячейку прямо в ней, курсор встаёт в конец текста. Повторное нажатие переключает режимы «ввод» и «правка»: в одном стрелки двигают курсор в тексте, в другом выбирают другую ячейку.
- <span class="kbd">Alt+Enter</span> – новая строка внутри ячейки.
- <span class="kbd">Ctrl+Enter</span> – подтвердить ввод и заполнить всё выделение одним значением или формулой.
- <span class="kbd">F4</span> – при вводе ссылки переключает варианты `A1`, `$A$1`, `A$1` и `$A1`. Вне редактирования повторяет последнее действие.
- <span class="kbd">Ctrl+;</span> – вставить сегодняшнюю дату как фиксированное значение. <span class="kbd">Ctrl+Shift+;</span> вставляет текущее время.
- <span class="kbd">Ctrl+Z / Ctrl+Y</span> – отмена и повтор.

## Перемещение

- <span class="kbd">Ctrl+Стрелка</span> – перейти к краю текущего блока данных. В пустой области переходит к следующей заполненной ячейке.
- <span class="kbd">Ctrl+Home / Ctrl+End</span> – перейти в `A1` или в последнюю использованную ячейку.
- <span class="kbd">Ctrl+PgDn / Ctrl+PgUp</span> – следующий и предыдущий лист.
- <span class="kbd">F5 или Ctrl+G</span> – «Переход»: введите адрес ячейки или имя. Кнопка **Выделить…** выделяет ячейки по типу (пустые, ошибки, формулы, только видимые).
- <span class="kbd">Ctrl+F / Ctrl+H</span> – поиск и замена.

## Выделение

- <span class="kbd">Ctrl+Пробел</span> – выделить весь столбец. Если вместо этого переключается раскладка, измените это сочетание в языковых настройках Windows.
- <span class="kbd">Shift+Пробел</span> – выделить всю строку.
- <span class="kbd">Ctrl+A</span> – выделить текущую область данных; повторное нажатие выделяет весь лист.
- <span class="kbd">Shift+Стрелка</span> – расширить выделение на одну ячейку. С <span class="kbd">Ctrl</span> расширяет до края данных: <span class="kbd">Ctrl+Shift+Стрелка</span>.
- <span class="kbd">Ctrl+Shift+End</span> – расширить выделение до последней использованной ячейки.
- <span class="kbd">Alt+;</span> – выделить только видимые ячейки. Пригодится перед копированием отфильтрованного списка, чтобы не скопировать скрытые строки.

## Заполнение и формулы

- <span class="kbd">Ctrl+D</span> – заполнить вниз: скопировать верхнюю ячейку выделения в ячейки ниже. <span class="kbd">Ctrl+R</span> заполняет вправо.
- <span class="kbd">Alt+=</span> – вставить `СУММ` для соседнего диапазона. Если выделено несколько ячеек, итоги появятся во всех сразу.
- <span class="kbd">Ctrl+E</span> – мгновенное заполнение: введите результат для первой строки и нажмите сочетание, чтобы продолжить шаблон.
- <span class="kbd">Ctrl+\`</span> – показать формулы вместо значений (клавиша слева от <span class="kbd">1</span>). Повторное нажатие возвращает значения.
- <span class="kbd">Ctrl+Shift+Enter</span> – ввод формулы массива в старых версиях Excel.

## Копирование и вставка

- <span class="kbd">Ctrl+C / Ctrl+X / Ctrl+V</span> – копировать, вырезать, вставить.
- <span class="kbd">Ctrl+Alt+V</span> – «Специальная вставка». В диалоге нажимайте подчёркнутую букву нужного пункта, например чтобы вставить только значения или умножить на число (см. [преобразование чисел-как-текст](/ru/articles/text-numbers-to-numeric-values/)).
- <span class="kbd">Ctrl+Shift++ / Ctrl+-</span> – вставить или удалить ячейки, строки или столбцы. Сначала выделите строку или столбец целиком.
- <span class="kbd">Ctrl+9 / Ctrl+0</span> – скрыть выделенные строки или столбцы.

## Форматирование и файлы

- <span class="kbd">Ctrl+1</span> – диалог «Формат ячеек».
- <span class="kbd">Ctrl+T</span> – превратить диапазон в таблицу (см. [очистку данных](/ru/articles/best-practices-for-cleaning-data-in-excel/)).
- <span class="kbd">Ctrl+Shift+L</span> – включить или выключить фильтры.
- <span class="kbd">Ctrl+B / Ctrl+I / Ctrl+U</span> – полужирный, курсив, подчёркивание.
- <span class="kbd">F12</span> – «Сохранить как».
- <span class="kbd">Ctrl+S</span> – сохранить. Стоит нажимать каждые несколько минут.

Сочетания одинаковы в английской и русской версиях Excel, если не сказано иное. На Mac большинство сочетаний с <span class="kbd">Ctrl</span> используют <span class="kbd">Cmd</span>, а некоторые отличаются, поэтому смотрите справку Excel для своей версии.
