# Курсы валют с сайта НБУ на VBA

Две пользовательские функции Excel, которые загружают курсы валют НБУ на заданную дату или на сегодня, и о том, когда их лучше не использовать.

В комментариях к предыдущей [статье](/ru/articles/currency-rates-from-cbr-vba/) про загрузку курсов валют с сайта ЦБ РФ спросили про аналогичную задачу для Национального банка Украины (НБУ). Вот готовый макрос для этого. Процесс такой же, как подробно описан в той статье, поэтому сразу перейдём к результату.

Макрос объявляет две пользовательские функции (UDF), которые можно использовать в формулах на листе Excel.

## Курс на заданную дату

    =GetNbuCurrency("RUB";"5/31/2020")

Загружает курс выбранной валюты на заданную дату. Данные берутся из официального API НБУ:

    https://bank.gov.ua/NBU_Exchange/exchange?date=31.12.2019

## Курс на сегодня

    =NbuTodayCurrency(C10;ТДАТА())

Загружает курс валюты на текущую дату. Значение второго аргумента может быть любым. Функция `ТДАТА` (`NOW` в английской версии Excel) нужна только для того, чтобы принудительно пересчитывать значение (и запрашивать API) при каждом изменении этого аргумента: при открытии книги и даже при изменении любой ячейки в любой открытой книге Excel.

Будьте осторожны с этой функцией. Если в книге много ячеек с такой формулой, можно завалить сайт запросами, и это может закончиться баном. Разумнее разместить формулу в одном месте (например, на отдельном листе) и ссылаться на эту ячейку в остальных формулах.
