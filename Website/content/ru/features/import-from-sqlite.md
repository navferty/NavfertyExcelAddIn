# Импорт из SQLite

Импортируйте таблицы и представления базы SQLite в новую книгу. Каждая выбранная таблица, представление или результат запроса помещается на отдельный лист; в первой строке находятся названия столбцов.

## Как использовать

1. На вкладке **Navferty's Tools** выберите **Импорт из SQLite**.
2. Выберите файл базы данных `.db`, `.sqlite` или `.sqlite3`. В окне выбора также доступен фильтр всех файлов.
3. Отметьте одну или несколько таблиц или представлений. Подсчёт записей выполняется в фоновом режиме; для недоступного объекта число записей может быть неизвестно. Кнопка **Выбрать все** отмечает все объекты сразу, после чего ненужные можно снять. Если число записей превышает ограничение Excel, появится предупреждение; не отмечайте этот объект или ограничьте результат запросом.
4. При необходимости введите один запрос `SELECT` без точки с запятой. Можно импортировать только результат запроса или добавить его к выбранным таблицам и представлениям.
5. Нажмите **Импорт**. Результаты появятся в новой книге.

База открывается только для чтения. SQL `NULL` становится пустой ячейкой, значения BLOB кодируются как текст base64, а целые числа длиннее 15 цифр импортируются как текст, чтобы сохранить точность. Текст форматируется как текст, чтобы предотвратить выполнение формул.

Сначала значения преобразуются в соответствии с объявленным типом столбца. Если преобразование не удалось, значение импортируется в соответствии с его классом хранения SQLite. Успешные преобразования, например даты в .NET `DateTime`, могут изменить исходное представление значения.

Результаты, превышающие ограничения Excel (1 048 575 строк данных и заголовок, 16 384 столбца или 32 767 символов в ячейке), импортировать нельзя. При ошибке, например при неверном или заблокированном файле, сообщение выводится пользователю, а частично заполненная книга не сохраняется.

Чтобы создать базу из существующей книги, см. [Экспорт в SQLite](/ru/features/export-to-sqlite/).

Надстройка бесплатная, с открытым кодом. [Инструкция по установке](/ru/install/).
