# Импорт из SQLite

Импортируйте таблицы и представления базы SQLite в новую книгу. Каждая выбранная таблица, представление или результат запроса помещается на отдельный лист; в первой строке находятся названия столбцов.

## Как использовать

1. На вкладке **Navferty's Tools** выберите **Импорт из SQLite**.
2. Выберите файл базы данных `.db`, `.sqlite` или `.sqlite3`. В окне выбора также доступен фильтр всех файлов.
3. Отметьте одну или несколько таблиц или представлений. Подсчёт записей выполняется в фоновом режиме; для недоступного объекта число записей может быть неизвестно. Кнопка **Выбрать все** отмечает все объекты сразу, после чего ненужные можно снять. Если число записей превышает ограничение Excel, появится предупреждение; не отмечайте этот объект или ограничьте результат запросом.
4. При необходимости введите один запрос `SELECT` без точки с запятой. Можно импортировать только результат запроса или добавить его к выбранным таблицам и представлениям.
5. Нажмите **Импорт**. Результаты появятся в новой книге.

База открывается только для чтения.

## Как преобразуются значения

SQLite допускает значения разных классов хранения в одном столбце. Для каждого значения таблицы, представления или результата запроса провайдер SQLite сначала выполняет обычное преобразование, которое может учитывать объявленный тип столбца. При исключении формата, недопустимого приведения или переполнения импортёр считывает значение в соответствии с его классом хранения SQLite. Другие ошибки по-прежнему прерывают импорт.

Полученные значения записываются следующим образом:

| Значение, возвращённое провайдером или считанное по классу хранения | Результат в Excel |
| --- | --- |
| `NULL` | Пустая ячейка |
| Целое число (`Int64`) | Число, если в нём не более 15 цифр; иначе текст для сохранения точности |
| Вещественное число (`Double`) | Число |
| Текст | Текст |
| BLOB | Текст в кодировке base64 (например, `X'00FF'` становится `AP8=`) |
| .NET `DateTime` | Текст даты и времени в формате для обратного преобразования, с сохранением долей секунды и признака типа/смещения при наличии; это не ячейка даты Excel |

Например, в столбце `DATETIME` значение `2026-01-02 03:04:05.1234567` может быть преобразовано провайдером в `DateTime` и импортировано как `2026-01-02T03:04:05.1234567`. Если в другой строке находится `not a date`, преобразование не удастся и текст будет импортирован без изменений. Импорт последующих строк продолжится.

Чтение по классу хранения выполняется только при указанных выше исключениях преобразования. Успешное преобразование провайдера может уже изменить значение или его представление, поэтому точное сохранение каждого исходного значения SQLite **не гарантируется**. Функции даты и времени SQLite, например `datetime()`, возвращают текст и сами по себе не создают .NET `DateTime`.

Перед записью диапазоны форматируются как текст, чтобы импортированный текст не выполнялся как формула. Числовые значения при этом записываются как числа.

Результаты, превышающие ограничения Excel (1 048 575 строк данных и заголовок, 16 384 столбца или 32 767 символов в ячейке), импортировать нельзя. При ошибке, например при неверном или заблокированном файле, сообщение выводится пользователю, а частично заполненная книга не сохраняется.

Чтобы создать базу из существующей книги, см. [Экспорт в SQLite](/ru/features/export-to-sqlite/).

Надстройка бесплатная, с открытым кодом. [Инструкция по установке](/ru/install/).
