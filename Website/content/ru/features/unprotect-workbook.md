## Как использовать

Применяйте команду только к книгам, которые вам разрешено изменять. Сохраните книгу, создайте резервную копию, затем нажмите **Защита файла** и подтвердите предупреждение. Команда закроет книгу без сохранения дальнейших изменений, изменит файл на диске и откроет его снова.

Например, можно снять защиту листов и структуры сохранённого файла `.xlsx`. Для `.xlsm` команда также пытается изменить защиту VBA-проекта.

**Важно:** При подтверждении несохранённые изменения теряются. Команда изменяет исходный файл и поддерживает `.xlsx` и `.xlsm`, но не снимает шифрование с паролем на открытие. Работайте с резервной копией, особенно для книг с макросами: успешное восстановление VBA-проекта не гарантируется.

Надстройка бесплатная, с открытым кодом. [Инструкция по установке](/ru/install/).
