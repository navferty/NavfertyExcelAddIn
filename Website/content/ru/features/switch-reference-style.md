# Стиль ссылок (A1/R1C1)

Переключает способ записи ссылок на ячейки в формулах между стилем A1 (`=B2*C2`) и стилем R1C1 (`=RC[-1]*RC[-2]`).

## Как использовать

Нажмите **Стиль ссылок (A1/R1C1)**, чтобы переключить стиль ссылок Excel; повторное нажатие вернёт прежний стиль. Например, ссылка на соседнюю ячейку слева в зависимости от положения формулы может записываться как `A1` или `RC[-1]`.

Изменяется способ отображения и ввода ссылок, а не сам расчёт. Настройка применяется к приложению Excel и может затронуть другие открытые книги.

Надстройка бесплатная, с открытым кодом. [Инструкция по установке](/ru/install/).
