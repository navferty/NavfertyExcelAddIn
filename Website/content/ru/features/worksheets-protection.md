## Как использовать

Откройте книгу и нажмите **Защита листов**. Выберите **Установить** или **Снять**, отметьте нужные листы, при необходимости введите пароль и нажмите **Выполнить**. В списке отображаются листы, подходящие для выбранного действия.

Например, выберите **Установить**, отметьте два незащищённых листа и введите пароль, чтобы защитить оба. Для снятия защиты с листов с паролем укажите соответствующий пароль. При ошибке появится сообщение, а окно останется открытым для проверки.

Команда работает с защитой листов, а не с шифрованием файла. Пароль при установке защиты необязателен; если вы его используете, сохраните его в безопасном месте.

Надстройка бесплатная, с открытым кодом. [Инструкция по установке](/ru/install/).
