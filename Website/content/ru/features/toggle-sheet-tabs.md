# Ярлычки листов

Одним щелчком показывает или скрывает ярлычки листов внизу окна Excel.

## Как использовать

Нажмите **Ярлычки листов**, чтобы скрыть ярлычки листов в активном окне книги. Повторное нажатие покажет их снова. Например, можно скрыть ярлычки при показе отчёта и вернуть их для перехода между листами.

Команда изменяет отображение ярлычков в активном окне, но не удаляет и не скрывает сами листы.

Надстройка бесплатная, с открытым кодом. [Инструкция по установке](/ru/install/).
