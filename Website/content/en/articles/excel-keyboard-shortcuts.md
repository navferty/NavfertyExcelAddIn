# Excel keyboard shortcuts that save the most time

A practical set of shortcuts for editing, navigating, selecting, filling and pasting in Excel, grouped by task.

Most of the time saved with the keyboard comes from a small set of shortcuts used constantly. These are grouped by what you are doing. Learn a few from one group, use them for a week, then add more.

## Editing a cell

- <span class="kbd">F2</span> – edit the cell in place, with the cursor at the end of the text. Press it again to switch between "enter" and "edit" modes, where the arrow keys move the cursor or select another cell.
- <span class="kbd">Alt+Enter</span> – new line inside a cell.
- <span class="kbd">Ctrl+Enter</span> – confirm and fill the whole selection with the same value or formula.
- <span class="kbd">F4</span> – while typing a reference, cycle between `A1`, `$A$1`, `A$1` and `$A1`. Outside of editing it repeats the last action.
- <span class="kbd">Ctrl+;</span> – insert today's date as a fixed value. <span class="kbd">Ctrl+Shift+;</span> inserts the current time.
- <span class="kbd">Ctrl+Z / Ctrl+Y</span> – undo and redo.

## Moving around

- <span class="kbd">Ctrl+Arrow</span> – jump to the edge of the current block of data. Pressed in an empty area it jumps to the next filled cell.
- <span class="kbd">Ctrl+Home / Ctrl+End</span> – go to `A1` or to the last used cell.
- <span class="kbd">Ctrl+PgDn / Ctrl+PgUp</span> – next and previous sheet.
- <span class="kbd">F5 or Ctrl+G</span> – Go To: type a cell address or a name. The **Special…** button selects cells by type (blanks, errors, formulas, visible cells only).
- <span class="kbd">Ctrl+F / Ctrl+H</span> – find and replace.

## Selecting

- <span class="kbd">Ctrl+Space</span> – select the whole column. If it switches the keyboard layout instead, change that shortcut in the Windows language settings.
- <span class="kbd">Shift+Space</span> – select the whole row.
- <span class="kbd">Ctrl+A</span> – select the current data region; pressed again, the whole sheet.
- <span class="kbd">Shift+Arrow</span> – extend the selection by one cell. Combined with <span class="kbd">Ctrl</span> it extends to the edge of the data: <span class="kbd">Ctrl+Shift+Arrow</span>.
- <span class="kbd">Ctrl+Shift+End</span> – extend the selection to the last used cell.
- <span class="kbd">Alt+;</span> – select only visible cells. Useful before copying a filtered list, so hidden rows are not copied.

## Filling and formulas

- <span class="kbd">Ctrl+D</span> – fill down: copy the top cell of the selection into the cells below. <span class="kbd">Ctrl+R</span> fills right.
- <span class="kbd">Alt+=</span> – insert `SUM` for the neighbouring range. With several cells selected it adds totals to all of them at once.
- <span class="kbd">Ctrl+E</span> – Flash Fill: type the result for the first row, then press it to continue the pattern.
- <span class="kbd">Ctrl+\`</span> – show formulas instead of values (the key to the left of <span class="kbd">1</span>). Press again to switch back.
- <span class="kbd">Ctrl+Shift+Enter</span> – enter an array formula in older versions of Excel.

## Copying and pasting

- <span class="kbd">Ctrl+C / Ctrl+X / Ctrl+V</span> – copy, cut, paste.
- <span class="kbd">Ctrl+Alt+V</span> – Paste Special. In the dialog, press the underlined letter of the option, for example to paste values only or to multiply by a number (see [converting text numbers to numeric values](/en/articles/text-numbers-to-numeric-values/)).
- <span class="kbd">Ctrl+Shift++ / Ctrl+-</span> – insert or delete cells, rows or columns. Select a whole row or column first.
- <span class="kbd">Ctrl+9 / Ctrl+0</span> – hide the selected rows or columns.

## Formatting and files

- <span class="kbd">Ctrl+1</span> – Format Cells dialog.
- <span class="kbd">Ctrl+T</span> – turn the range into a table (see [cleaning data](/en/articles/best-practices-for-cleaning-data-in-excel/)).
- <span class="kbd">Ctrl+Shift+L</span> – toggle filters.
- <span class="kbd">Ctrl+B / Ctrl+I / Ctrl+U</span> – bold, italic, underline.
- <span class="kbd">F12</span> – Save As.
- <span class="kbd">Ctrl+S</span> – save. Worth pressing every few minutes.

Shortcuts are the same in English and Russian Excel unless noted. On a Mac most <span class="kbd">Ctrl</span> shortcuts use <span class="kbd">Cmd</span>, and some differ, so check the Excel help for your version.
